MSc thesis project

Parameterized Robotic Sample Dispensing

A parameter-driven software framework for configuring, validating, and executing robotic sample-dispensing workflows using a DOBOT MG400.

Robotics Automation Python Mechanical design

The problem

Laboratory robot applications are often built around fixed station layouts and hard-coded task sequences. Moving a station, changing the wafer size, adding materials, or modifying the dispensing order may therefore require changes to the robot program.

The solution

I developed a reusable framework that separates experiment-specific settings from the main robot execution logic.

Station geometry, wafer patterns, material definitions, motion parameters, calibrated poses, and safety constraints are stored as configuration data. The framework uses this information to generate and validate the required robot movements before execution.

Key features

  • Configurable tip, liquid, wafer, and waste stations
  • Automatic generation of 3-inch and 4-inch wafer patterns
  • Calibrated station poses and safe joint waypoints
  • Workspace, station-footprint, and approach-pose validation
  • Mixing and non-mixing material workflows
  • Operator and developer interfaces built with Streamlit
  • Runtime monitoring, stop handling, and execution logging
  • 3D-printed pipette holder designed for the MG400

My contribution

  • Designed the overall software architecture and configuration model
  • Implemented workflow generation and station-action logic
  • Developed wafer-point generation and material sequencing
  • Integrated the framework with the Common Robot Interface and DOBOT MG400 controller
  • Developed the operator and developer user interfaces
  • Implemented pose, workspace, and geometry validation
  • Designed and 3D-printed the pipette mounting system
  • Planned and completed the experimental validation

Validation

The framework was evaluated through dry-run execution using controller-reported TCP position data.

  • Executed complete workflows across tip, liquid, wafer, and waste stations
  • Regenerated trajectories after changing the wafer location
  • Adapted the workflow from a 4-inch to a 3-inch wafer
  • Tested different robot speed settings
  • Completed workflows with and without mixing logic
  • Achieved mean XY repeatability deviations below 0.009 mm across the tested speeds

Mechanical holder

The pipette holder was modeled in CAD, manufactured through 3D printing, and evaluated using static structural analysis.

  • Maximum Von Mises stress: 27.9 MPa
  • Selected PLA allowable strength: 40 MPa
  • Estimated safety factor: approximately 1.43

Project limitations

The project validated robot motion, reconfiguration, workflow execution, and controller-reported repeatability. It did not evaluate delivered liquid volume, droplet formation, or physical sample-placement accuracy.

What this project demonstrates

Robot programming, configurable automation, software architecture, workspace validation, user-interface development, mechanical prototyping, system integration, and experimental validation.
