Independent MSc project

Parameterized Robotic Sample Dispensing

A configurable software framework for automating laboratory sample-dispensing workflows with a DOBOT MG400 robot.

RoboticsAutomationPythonSystem integration

The problem

Laboratory robot applications are often built around fixed station layouts and hard-coded sequences. Changing a sample holder, liquid configuration, dispensing order, or workcell layout can therefore require substantial changes to the robot program.

The approach

I developed a parameterized framework that separates process configuration, station geometry, workflow generation, validation, and robot execution.

Process configuration
Workflow generation
Pose validation
Motion execution
DOBOT MG400

My contribution

  • Designed the parameterized software architecture and workflow-generation logic.
  • Implemented configurable tip, liquid, wafer, and waste stations.
  • Developed operator and developer interfaces for execution and configuration.
  • Integrated the framework with the Common Robot Interface and the MG400 controller.
  • Implemented geometry, workspace, and pose validation.
  • Evaluated reconfiguration, robot motion, and dry-run workflow execution.

Validation scope

The system was evaluated through dry-run robot execution, multiple station and wafer configurations, motion analysis, and repeatability tests. Active liquid-volume and droplet-placement validation were outside the experimental scope.

What this project demonstrates

Robot programming, configurable automation, software architecture, physical-system integration, operator-interface design, validation, and experimental engineering.
