Bird Species Classification from Audio

A comparison of convolutional and deep variational autoencoder approaches for classifying bird species from environmental audio recordings.

Deep learning Audio processing PyTorch MFCCs

The problem

Passive acoustic monitoring can support biodiversity research by identifying animal species from environmental recordings. However, real-world audio contains background noise, overlapping calls, variable recording quality, and species with similar vocalizations.

The dataset

The project used a subset of 15 bird species from the BirdCLEF 2025 dataset. The recordings were collected in the Magdalena Valley in Colombia and represent authentic environmental conditions.

Audio preparation

  • Converted the original OGG recordings to WAV format
  • Resampled the recordings to 16,000 Hz
  • Extracted Mel-Frequency Cepstral Coefficients
  • Used 13 MFCC coefficients and 40 mel filters
  • Padded or trimmed the feature sequences to a consistent size

Species prediction

Two deep learning approaches were implemented and compared using the same dataset split.

Convolutional Neural Network

The CNN treated the MFCC representations as two-dimensional time-frequency inputs. Three convolutional blocks were used to detect local frequency and temporal patterns before producing a prediction for one of the 15 species.

Deep Variational Autoencoder

The DVAE used a GRU-based encoder and decoder with a 64-dimensional latent space. A classification head was connected to the latent representation so the model could learn both to reconstruct MFCC sequences and classify species.

Training

  • Implemented both models using PyTorch
  • Used an 80% training and 20% test split
  • Trained the CNN with cross-entropy loss
  • Trained the DVAE using reconstruction loss, KL divergence, and classification loss
  • Applied Gaussian noise, time masking, and frequency masking to improve CNN robustness

Results

  • CNN test accuracy: approximately 68.8%
  • DVAE-based classification accuracy: approximately 50.2%
  • The CNN converged more quickly and produced more stable classification results
  • The DVAE learned partial class structure, but several species remained overlapped in the latent space

The CNN performed better because it was optimized directly for supervised classification. The DVAE had to balance reconstruction, latent-space regularization, and classification at the same time.

Evaluation

Model performance was evaluated using classification accuracy, training-loss curves, and confusion matrices. A t-SNE visualization was also used to inspect how the DVAE organized bird species within its latent space.

Limitations

Some species remained difficult to distinguish because their vocalizations contained similar time-frequency characteristics. The DVAE also struggled to create clearly separated latent clusters while simultaneously reconstructing the MFCC inputs.

What this project demonstrates

Audio signal processing, MFCC feature extraction, deep learning, representation learning, PyTorch model development, data augmentation, experimental comparison, and model evaluation.
