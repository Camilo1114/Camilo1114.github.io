Real-Time Resistor Detection

A computer-vision system that detects resistors in real time using embedded machine learning on a Raspberry Pi.

Embedded AI Computer vision Raspberry Pi TensorFlow Lite

The problem

Electronics laboratories often contain mixed and unsorted components from prototyping, repairs, and disassembly. Manually identifying small parts can be slow and error-prone.

The objective was to build a low-cost embedded system that could determine in real time whether an object shown to the camera was a resistor or a non-resistor.

The system

Camera frame
Image preprocessing
MobileNetV2
TensorFlow Lite
Live prediction
  • Raspberry Pi 4
  • Raspberry Pi Camera Module 3 with autofocus
  • MobileNetV2 transfer-learning model
  • TensorFlow and TensorFlow Lite

  • Real-time camera inference with confidence and latency display

Dataset collection

Images were collected directly using the Raspberry Pi camera. A small Flask interface displayed the live camera feed and allowed each captured image to be labeled as either resistor or non-resistor.

The dataset included different resistor orientations, lighting conditions, backgrounds, electronic components, wires, and objects with similar visual characteristics.

Data preparation

  • Removed blurred, incorrectly labeled, and poorly framed images
  • Cropped and resized all images to 224 × 224 pixels
  • Applied rotations, translations, zoom, and horizontal flipping
  • Used dynamic data augmentation during model training

Model development

MobileNetV2 was selected because it provides a practical balance between accuracy, model size, and inference cost for embedded devices.

The pretrained ImageNet classification head was replaced with a lightweight binary classifier consisting of global average pooling, dropout, and a sigmoid output.

Training was completed in two phases:

  1. The MobileNetV2 backbone was frozen while the new classification head was trained.
  2. Approximately 30% of the upper layers were unfrozen and fine-tuned using a lower learning rate.

Quantization

The trained model was converted to TensorFlow Lite and evaluated in two formats:

  • Standard FP32 model
  • Quantized INT8 model

Quantization reduced the model's arithmetic precision to improve inference performance on the Raspberry Pi while preserving most of its classification accuracy.

Results

  • Training validation accuracy remained between 97% and 100%
  • Raspberry Pi FP32 accuracy: approximately 97.5%
  • Raspberry Pi INT8 accuracy: approximately 95.5%
  • Raspberry Pi FP32 inference latency: approximately 76.6 ms
  • Raspberry Pi INT8 inference latency: approximately 51.1 ms
  • INT8 provided the best balance between accuracy and real-time performance on the Raspberry Pi

Limitations

The training dataset contained only one main resistor color and a limited number of examples. Some objects with resistor-like shapes therefore produced false-positive or uncertain predictions.

A larger dataset containing more resistor types, colors, backgrounds, lighting conditions, and visually similar electronic components would improve generalization.

What this project demonstrates

Embedded machine learning, computer vision, transfer learning, model quantization, TensorFlow Lite deployment, dataset development, Raspberry Pi integration, and real-time performance evaluation.
