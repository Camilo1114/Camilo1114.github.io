Embedded ML for Resistor Classification

A collaborative embedded machine-learning system for classifying electrical resistors from visual data on resource-constrained hardware.

The problem

Resistor values are encoded through coloured bands. Automatically reading them requires visual classification while working within the memory, compute, and latency limits of embedded hardware.
