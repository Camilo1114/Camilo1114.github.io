Hyperspectral Polymer Identification

A two-stage machine learning pipeline for detecting plastics and identifying PET from hyperspectral reflectance measurements.

Machine learning Hyperspectral imaging Python Material classification

The problem

Different polymers can look similar in conventional images while having different reflectance patterns across the electromagnetic spectrum. This makes standard RGB-based sorting difficult, especially in recycling applications.

Hyperspectral imaging captures reflectance across hundreds of wavelength bands, providing information that can be used to distinguish materials based on their spectral characteristics rather than their visible appearance.

Project goal

The project investigated whether machine learning models trained on public hyperspectral datasets could identify PET and then be applied directly to measurements from a different imaging system: the NEWTEC BUTEO.

Data and measurements

Public hyperspectral datasets were used for model training, including spectra from PET, polyethylene, polypropylene, polystyrene, organic matter, water, and other non-plastic materials.

Local validation measurements were collected using the NEWTEC BUTEO pushbroom hyperspectral imaging system. The system operates from 430 to 1000 nanometers and records 330 spectral bands.

The measured samples included LEGO pieces, plastic waste objects, and a PETG sample used to test cross-system model transfer.

Preprocessing

  • Recorded white and dark references for reflectance calibration
  • Selected regions of interest from the hyperspectral images
  • Calculated mean reflectance spectra for each selected region
  • Interpolated all spectra to a shared 430–1000 nm wavelength grid
  • Standardized the features using a scaler fitted on the training data
  • Reused the same preprocessing components during NEWTEC inference

Material prediction

Instead of treating the problem as a single multiclass classification task, the pipeline was divided into two binary decisions.

  1. Determine whether the measured spectrum represents plastic or non-plastic material.
  2. For spectra identified as plastic, determine whether the material is PET or another polymer.

This structure reduces the risk of incorrectly identifying non-plastic materials as PET.

Machine learning models

Both classification stages used Support Vector Machines with a radial basis function kernel.

SVMs were selected because they are suitable for high-dimensional, nonlinear spectral data and can perform reliably when collecting large labeled industrial datasets is impractical.

Probabilistic model outputs were used to apply confidence thresholds at both stages of the decision process.

Results on public data

The pipeline successfully separated plastic spectra from non-plastic materials and distinguished PET from other polymers in the public datasets.

For the PET-versus-PE classification task, the model achieved:

  • Overall accuracy: 95%
  • PET precision: 0.88
  • PET recall: 0.95
  • PET F1-score: 0.91
  • PE precision: 0.98
  • PE recall: 0.95

Transfer to the NEWTEC system

The trained preprocessing and classification pipeline was applied directly to PETG spectra exported from the NEWTEC system without retraining or parameter adjustment.

Two spectra were extracted from separate regions of the same PETG sample. Both produced consistent results:

  • Plastic probability for both spectra: 1.000
  • PET probability for the first spectrum: 0.882
  • PET probability for the second spectrum: 0.877
  • Both spectra received a final PET-positive classification

Because PETG is chemically related to PET, these results indicate that the model detected PET-like spectral characteristics. They do not demonstrate reliable separation between PET and PETG.

Limitations

The NEWTEC validation dataset was small and contained limited material diversity. Differences in sensor response, illumination, noise, and spectral amplitude were also observed between the public training data and the NEWTEC measurements.

The system should therefore be considered a proof of concept rather than a production-ready recycling classifier. A larger validation set with more polymers, non-plastic materials, colors, surfaces, and acquisition settings would be required to evaluate reliability and false detections.

What this project demonstrates

Hyperspectral imaging, spectral-data processing, reflectance calibration, machine learning, nonlinear classification, cross-system inference, experimental data collection, and careful evaluation of model-transfer limitations.
