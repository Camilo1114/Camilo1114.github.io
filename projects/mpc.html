Model Predictive Control for a Multi-Tank System

A nonlinear model predictive control system with Extended Kalman Filter state estimation for regulating water levels in an interconnected multi-tank process.

Model predictive control Nonlinear systems MATLAB Simulink

The problem

The project used an experimental system of interconnected water tanks controlled through a pump and multiple valves.

The objective was to make the water levels in the upper and middle tanks follow changing reference values while accounting for nonlinear flow behavior, actuator limits, sensor noise, and disturbances.

The system

The process was modeled as a nonlinear multiple-input, multiple-output system.

  • Controlled outputs: water levels in Tank 1 and Tank 2
  • Manipulated inputs: pump flow and two control-valve signals
  • Nonlinear outflow behavior governed by the valve orifice laws
  • Nonlinear relationship between pump PWM and water inflow
  • Maximum permitted water level of 0.35 meters

Development workflow

System identification
Nonlinear modeling
MPC design
EKF estimation
Plant testing

System identification

Experimental measurements were used to identify the pump and valve behavior before designing the controller.

  • Measured pump flow at different PWM input values
  • Estimated manual-valve coefficients from tank-draining tests
  • Estimated nonlinear flow exponents using least-squares fitting
  • Estimated control-valve coefficients at multiple valve inputs
  • Implemented pump and valve relationships as lookup tables

Nonlinear model

The tank dynamics were derived from mass-balance equations. The model included the pump inflow, flow between tanks, and outflow through the manual and controlled valves.

The nonlinear system was implemented in MATLAB and Simulink and compared with measurements from the physical plant.

Model predictive controller

The continuous-time nonlinear equations were discretized using the Forward Euler method.

The controller used an incremental input formulation. Instead of directly optimizing the actuator values, the MPC calculated changes in:

  • Pump inflow
  • Tank 1 control-valve input
  • Tank 2 control-valve input

At every sampling step, the nonlinear model was linearized around the current operating point. The controller then predicted future tank levels and selected the input sequence that balanced reference tracking with control effort.

Only the first calculated control increment was applied before the optimization was repeated using the next system measurement.

Controller implementation

  • Incremental nonlinear MPC formulation
  • Local Jacobian-based linearization at each sampling step
  • Prediction and control horizons
  • Quadratic tracking and control-effort cost function
  • Initial weight selection using Bryson's rule
  • Actuator saturation based on physical limits
  • Low-pass filtering to smooth control signals

Extended Kalman Filter

An Extended Kalman Filter was added because raw measurements and the nominal model were affected by sensor noise, parameter errors, leakage, valve nonlinearities, and other unmodeled disturbances.

The EKF state contained the two water levels and two additional disturbance states. These disturbance states allowed the observer to estimate slowly changing model errors and reduce steady-state offsets.

  • Predicted the nonlinear system state
  • Linearized the model using a Jacobian matrix
  • Corrected predictions using measured tank levels
  • Reduced measurement noise before the state entered the MPC
  • Estimated unmodeled disturbances affecting both tanks

Simulation results

Under nominal simulation conditions, the MPC tracked the reference values for both tanks with smooth transient behavior, no overshoot, and short settling times.

The MPC and EKF were also tested with simulated disturbances, including:

  • An external output disturbance introduced at 250 seconds
  • Changes to the manual-valve parameters at 400 seconds

The observer and controller compensated for both disturbances and returned the simulated system to the required operating condition.

Experimental results

The MPC and EKF were then connected to the physical multi-tank plant through Simulink.

  • The real system followed the changing references for both tanks
  • Tracking was slower than in simulation after large reference changes
  • The EKF reduced sensor noise and estimation bias
  • Tank-level estimation errors were approximately 0.02 meters
  • Pump and valve signals changed consistently with the requested filling and draining behavior

Limitations

The physical system did not perform as quickly as the simulated model. The main limitations were:

  • Actuator nonlinearities and dead zones
  • Sensor bias and measurement noise
  • Unmodeled system delays
  • Limited pump and valve parameter identification
  • Flow behavior influenced by hose geometry and curvature

The final controller was suitable for regulation and moderate reference changes, but improved actuator models and explicit delay handling would be required for faster tracking.

What this project demonstrates

Nonlinear dynamic modeling, system identification, model predictive control, Extended Kalman filtering, optimization, MATLAB and Simulink implementation, state estimation, control-system integration, and experimental validation.
